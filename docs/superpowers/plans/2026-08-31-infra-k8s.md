# Kubernetes AWS Infrastructure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `$subagent-driven-development` (recommended) or `$executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar a fundação AWS compartilhada da Fase 3: rede, EKS, ECR, add-ons, NLB, IAM/OIDC, segredo JWT, orçamento e pipelines.

**Architecture:** Um VPC em duas AZs hospeda workers EKS em subnets públicas e RDS/Lambdas em subnets privadas, sem NAT Gateway. Um NLB interno possui listeners 8080/8081 e target groups para os NodePorts 30080/30081 de hml/prod. O cluster é compartilhado, com EKS Pod Identity e add-ons gerenciados.

**Tech Stack:** Terraform `>=1.11,<2.0`, AWS Provider `~>6.0`, Random Provider `~>3.7`, módulos VPC `6.6.1` e EKS `21.24.1`, EKS/Kubernetes `1.35`, GitHub Actions, TFLint, Checkov.

**Spec:** `docs/superpowers/specs/2026-08-31-fase-3-aws-design.md`

## Global Constraints

- Região fixa: `us-east-1`.
- Nomes AWS usam somente ASCII e hífen, prefixados por `soat-oficina`.
- Cluster: Kubernetes `1.35`, node group `t3.medium`, `min=1`, `desired=1`, `max=2`.
- Rede: VPC `10.20.0.0/16`, duas AZs, sem NAT Gateway e sem acesso público ao RDS.
- Ambientes compartilhados: namespaces `hml` e `prod`.
- NLB único: listener 8080 -> NodePort 30080; listener 8081 -> NodePort 30081.
- GitHub Actions usa OIDC; nenhuma AWS access key é armazenada.
- Terraform state usa S3 versionado, criptografado e com `use_lockfile=true`.
- `terraform apply` e `destroy` nunca executam em Pull Request.

  target_type = "instance"
  vpc_id      = module.vpc.vpc_id

    protocol = "HTTP"
    path     = "/actuator/health"
    port     = "traffic-port"

  for_each = local.routing

    target_group_arn = aws_lb_target_group.environment[each.key].arn
  }
}
